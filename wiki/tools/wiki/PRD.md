# Wiki requirements

Provide browsable project documentation from authoritative repository files,
with working navigation and checked links. Keep publication separate from local
validation and use the approved public-site boundary.

The [SPEC](SPEC.md) owns publication, navigation, embeds, text-only checks,
browser acceptance, and deployment rules. Its browser checks provide the
interaction acceptance; the [ownership map](../../ownership.md) links the
implementation and all publication tests. Repository workflow acceptance remains
in the [infrastructure checklist](../../agents/infrastructure-acceptance.md).
