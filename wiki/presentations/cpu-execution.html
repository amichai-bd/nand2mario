The SM83 transforms bytes into architectural state. Follow a NOP from address 0100 to its retirement record.

Explore the reasoning

Architectural state means the registers and control state visible to software. Retirement is the completed event used by a debugger or scoreboard; a fetch alone is not completion.

01 · CPU execution · 02

Startup is not a retired NOP

With consecutive NOP bytes, the initial fetch ends at dot 4. The first NOP retires at dot 8 while the next opcode is fetched.

The first fetch primes execution; later fetches overlap the retiring NOP.

Explore the reasoning

A dot is one enabled emulated T-cycle. Fetch overlap avoids adding a fictitious extra M-cycle to every instruction. The first fetch produces no synthetic instruction record.

Prepare early. Commit once.

A memory request stays stable through T1–T3. T4 samples the read or commits the write; preparation must have no peripheral side effect.

Explore the reasoning

Imagine pausing after T2: resume must finish the same transaction once. A missing read response is a contract fault, not permission to stretch Game Boy time.

01 · CPU execution · 04

The next fetch is not the next PC

A JP to 0200 fetches its target at dot 20. Its retirement says pc_after=0200, even if the internal fetch cursor has advanced.

Bytes

C3 00 02 encode the destination.

Schedule

Fetches at dots 4, 8, 12; idle at 16; target at 20.

Observation

Record the next instruction address, not the internal cursor.

Explore the reasoning

Ask the audience what would break if the trace reported 0201: an independent instruction-by-instruction comparison would diverge even if execution looked correct.

01 · CPU execution · 05

Sleeping has several meanings

CPU HALT leaves peripheral time running. Host pause freezes emulated time. STOP follows the selected digital oscillator/wake policy.

HALT

Wait for an enabled interrupt request; the PPU still advances.

Host pause

Preserve phase and prepared transaction; transport continues.

STOP

Use qualified stable-clock wake, with documented analog limits.

Explore the reasoning

Do not infer these states from an unchanged PC. Their effects on time differ. The deterministic STOP model is an explicit approximation, not a measurement of unstable silicon clocks.
