03 · Clocks and CDC · 02

An enable is not another clock

The phase accumulator adds 65536 each system edge and wraps at 390625. Its carry advances one DMG dot.

Explore the reasoning

After N active edges there are floor(N × 65536 / 390625) ticks. Multiplying the ratio by 25 MHz gives 4,194,304 enables per second; all consumers still use clk_sys.

03 · Clocks and CDC · 03

Budget for the shortest gap

Tick gaps are five or six system edges. A four-dot M-cycle spans 23 or 24 edges, so memory service must fit the 23-edge case.

Average

Exact nominal DMG rate over each accumulator period.

Worst case

Five edges to the next dot; 23 to the next M-cycle boundary.

Failure

Missing service must fault rather than discard a tick.

Explore the reasoning

Average throughput cannot prove a deadline. Ask whether a service taking 24 edges is safe: some M-cycles allow it, but the shortest does not.

03 · Clocks and CDC · 04

Cross ownership, not a changing image

The frame bridge transfers a completed bank. Pixel scanout keeps its display bank while the system writes another.

Explore the reasoning

Synchronizing every pixel bus bit independently would not make a coherent frame. The crossing protocol keeps the offered bank stable while control passes between domains.

03 · Clocks and CDC · 05

Pause does not stop the monitor

Host pause freezes emulated phase and state. UART, CDC handshakes and VGA continue, so the host can inspect a stable machine.

Freeze

CPU/PPU emulated progress and fractional phase.

Continue

Transport and scanout on their running clocks.

Resume

Continue retained phase without catch-up dots.

Explore the reasoning

A hardware clock stopped indiscriminately would also stop the debugger that must resume it. Reset release still follows each domain’s synchronization contract.

03 · Clocks and CDC · 06

Each proof answers a different question

Simulation checks event ordering. FPGA timing checks constrained paths. A monitor test checks the connected display and clock tolerance.

Explore the reasoning

Nominal 60 Hz VGA and about 59.73 Hz DMG source frames intentionally differ. Simulation and generated timing evidence do not close the open physical acceptance gaps.
