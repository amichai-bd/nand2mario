An address selects behavior

A CPU read is more than an array index. Decoding chooses storage or a peripheral owner; arbitration decides whether the access is allowed.

Explore the reasoning

Memory-mapped I/O means a register is reached through the address space. Reading a timer register and reading RAM can share bus wires while having different behavior.

02 · Memory buses · 02

Two addresses can name one byte

The integration program writes 3C to C000 and reads it through E000. WRAM echo uses the same low thirteen address bits.

C000 and E000 converge on offset 0000; there is no echo copy to update.

Explore the reasoning

There is one WRAM store. A second echo array could pass simple reads after reset but fail when either alias is written. This example is part of the bounded integration program.

02 · Memory buses · 03

A register has a behavior owner

FF46 belongs to DMA, even though neighboring addresses belong to the PPU. A generic shadow register array would lose the command’s meaning.

Decode

Choose DMA for FF46 using generated address constants.

Behavior

The DMA owner interprets a committed write.

Storage

Memory remains the sole owner of the actual OAM bytes.

Explore the reasoning

Separate numeric address ownership from behavioral implementation. A decoder can select a future owner without proving that owner exists or behaves correctly.

02 · Memory buses · 04

Synchronous RAM needs a schedule

A read result arrives after a clocked read edge. The system must tag and deliver that result before the CPU’s fixed T4 consumption edge.

Explore the reasoning

Tags associate a response with its request. A stale valid byte can look plausible while belonging to an earlier address. Fixed service budgets make this a correctness condition.

Source: Raw store service

02 · Memory buses · 05

Arbitration preserves one truth

CPU, PPU and DMA share logical video storage. Access policy, paired OAM service and collision handling belong to named owners.

CPU

Commit through the access policy.

PPU

Read the same VRAM/OAM data through its service ports.

DMA

Resolve writes and collisions before the shared store.

Explore the reasoning

Multiple physical ports do not imply multiple logical copies. This distinction keeps a sprite update visible to the renderer without a separate synchronization copy.

Source: Stores and ownership

Test aliases and side effects

Check all decode boundaries, then check that preparation is harmless and a commit happens once. A byte-only test cannot expose every bus defect.

Explore the reasoning

The decoder’s documented fixture enumerates all 65,536 addresses and includes a wrong-echo-offset mutation. That proof is narrower than full peripheral or board acceptance.
