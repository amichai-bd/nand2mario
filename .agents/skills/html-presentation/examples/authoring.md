# Authoring examples

Good: explain the repository flow in three slides, reuse shared CSS/JS, and link
to `src/rtl/README.md` through `data-source`. Label it as a directory placeholder.
See the [working scaffold tour](../../../../wiki/presentations/scaffold-tour.html).

Bad: paste RTL into a slide, claim it is verified, export a PNG diagram, or copy
the slide runtime into each deck. The excerpt drifts, the claim lacks evidence,
and the diagram cannot be edited as text.

Try the template with a two-slide explanation of an existing tool. Verify its
source link opens the exact wiki file and works as a normal link standalone.
Report missing sources or undecided behavior; do not invent details.
