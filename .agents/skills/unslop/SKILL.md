# Unslop

Make project prose direct, natural, concise, and exact.

1. Identify the audience, purpose, required structure, and evidence.
2. Preserve every fact, decision, constraint, path, command, citation, number,
   status, and uncertainty.
3. Lead with the result, evidence, or decision.
4. Remove filler, repetition, meta narration, stock transitions, and needless
   structure.
5. Prefer familiar words, precise verbs, active voice, and short sentences.
6. Compare with the source. Restore anything whose removal changes meaning.

Preserve required headings, closing references, checkboxes, links, and code
spans. Leave clear prose unchanged. Use
[the check](templates/check.md) for high-risk edits and see
[the scenarios](examples/scenarios.md) for boundaries. See the style
[sources](references/sources.md).
