# PR body

Fill the [canonical PR template](../../../../.github/pull_request_template.md).
Save the filled body under `workdir/.tmp/pr/`; keep it while work or review needs it, then remove it with the worktree.

For a reported sustained hardware run, include its selected plan, continuous/whole
measurements and three verified native actual-snapshot PNG PR attachments under the
[owning evidence contract](../../../../src/dv/springtrail/ENDURANCE.md#selected-pr-image-attachments).
Record hashes/frame provenance and publication failures; commit no PNG bytes.
